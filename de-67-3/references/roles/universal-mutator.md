# Rare universal mutator role

```text
M_universal = whole current method + direct failure evidence
              -> isolated broad candidate + falsifiable proof plan
              -> independent owner decision
```

Enter only when the persisted due random cycle has exactly `k = 30` and lane `DFS.md`, and the
workspace roster explicitly proves `gpt-5.6-sol` at `ultra`. All three facts are required. Do not
redraw or reinterpret the cycle. Use a fresh Sol/ultra worker with `fork_turns="none"`. The clock
snapshots the adjacent persisted workspace roster when the exact rare draw becomes due. If that
snapshot does not prove the capability, this role is not entered: the clock exposes the exact draw
and unavailable reason, does not arm a universal component, and lets the ordinary stored-lane
review close the cycle. Do not substitute a weaker reviewer or rewrite the roster. Provisioning
Sol/ultra can make a future exact draw eligible; it cannot reinterpret this frozen snapshot.

## Explore the method

Set one learning goal: find the earliest method premise that causes work to drift, repeat, hide
evidence, or fail to close. Inspect, as relevant, the router, kernel, all role modules, mutable
guidelines, DFS mechanics, task and test design, debug/observation support, item-clock and attempt
schema, orchestration, guards, supervisor, and direct project evidence.

Challenge every inherited explanation, including the current division of roles. Mutation volume is
not fitness. The outcome is a causal method model and an honest route for testing a replacement.

## Freeze the candidate

Once the causal model and proof route exist, freeze a finite candidate gap set. Prepare the whole
method candidate in an isolated directory or worktree. It may add, remove, split, or rewrite method
parts when evidence supports that change.

The isolated candidate may challenge even kernel, clock, guard, and authority-check architecture.
It does not edit the live clock or evidence ledger. The candidate must include:

- the first contradicted premise and direct evidence;
- the exact files or behaviors changed;
- tests or observations that can falsify the new method;
- a protected-vector audit covering user outcome, proof strength, permissions, and preservation or
  explicit migration of every recorded attempt;
- migration and rollback consequences for existing `.de67/` environments.

Validate the persisted trigger and isolated whole-skill shape. Include an optional redesigned DFS
only as a paired before/candidate input:

```text
python <active-de-67-3-skill>/scripts/mutation_guard.py universal-review --baseline <method-baseline-dir> --candidate <method-candidate-dir> --state .de67/state/deadlines.sqlite3 --workspace-config .de67/state/workspace.json --lineage PROJECT --cycle N [--dfs-before <before-DFS> --dfs-candidate <candidate-DFS>]
```

This verdict does not promote or install the candidate. It does not replace the protected-vector
audit or independent owner-authorized review. It prints and durably stores an immutable receipt for
the exact lineage, cycle, trigger, Sol/ultra capability, candidate digest, and changed paths. Record
only the universal component as resolved by consuming that receipt; free-form evidence may annotate
the review but cannot substitute for it. The same cycle's ordinary stored-lane component still runs
unchanged.

The receipt binds the required `gpt-5.6-sol` / `ultra` reviewer profile and the immutable due-time
capability snapshot. It does not cryptographically authenticate which model authored the review;
that remains a cooperative workflow assertion.

```text
python <active-de-67-3-skill>/scripts/deadline_harness.py resolve-random-mutation --state .de67/state/deadlines.sqlite3 --lineage PROJECT --cycle N --component universal --receipt <receipt-id printed by universal-review> --evidence "<candidate location or independent-review annotation>"
```

## No self-promotion

This role cannot edit the live installed method or clock state, declare its own evidence sufficient,
weaken the user outcome or honest proof, falsify evidence, exceed authority, erase an attempt, or
request routine promotion. Return the isolated candidate and proof plan to an independent
owner-authorized review. A partial existing guard never validates the whole-method candidate.
