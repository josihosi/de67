# Controlled English for a DE67 work ledger

Use this medium profile when writing the active work ledger. The full writing guideline is
`controlled-english.md`, but a ledger writer does not need to load it merely to update current
state.

- Preserve identifiers, paths, commands, status values, and quoted errors exactly.
- Use concrete nouns and literal verbs. Name the responsible actor when the actor matters.
- Give each sentence one clear meaning. State a condition before its result or action.
- Separate an observation from an inference. Calibrate uncertainty.
- Record the current frontier, not the full event history. SQLite and linked artifacts own detailed
  history.
- Keep the latest material result, the smallest direct evidence reference, any uncertainty that
  changes the next action, and the next necessary action.
- Distinguish planned work from completed work. Do not silently replace a prior evidence claim.
- Apply the MSW deletion test. Delete text that does not change the honest state, proof, or next
  action.

Technical precision overrides these preferences. This profile is guidance, not a validator or a
formal ASD-STE100 compliance claim.
