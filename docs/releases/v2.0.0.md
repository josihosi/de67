# de67 2.0.0 — Welcome, Astra

You bring the idea. de67 keeps a team of Codex agents on it—and keeps a record of what actually works.

## The whole thing, in plain words

- **Talk it through.** Phase 1 helps you work out what you want before anyone starts building.
- **Check the ground.** Phase 2 reads the real code and writes down what the finished thing must do.
- **Get it built.** In Phase 3, Sol coordinates. Terra and Luna investigate, build, test, and fix. Independent jobs can run together.
- **Keep talking.** The coordinator can follow workers and steer work in flight. Workers get their task and the context they need.
- **Remember the work.** A ledger and clock keep results, deadlines, and handoffs across agent restarts. Configured Git checkpoints preserve changes for recovery.
- **Show the proof.** A patch is a change. A test shows what that change can do. de67 keeps those claims separate.
- **Welcome, Astra.** Astra now owns Phase 2 and reviews the delivery method at review points. It can change a failing approach, then hand work back to a fresh coordinator.
- **Steer it yourself.** Add a suggestion during a run. Ask for review at the next quiet junction, or save it for the next scheduled review.
- **See what is happening.** The new dashboard puts Sol in the sun, Terra and Luna on worker scales, and Astra in the stars. It shows deadlines, review counts, and where work is going. The visible tab updates in place every 30 seconds, keeps your reading position, and pauses while you select text or hide the tab.
- **See what it costs in tokens.** Campaign totals split into coordinator, workers, and mutator. The graph covers eight hours. Missing records are marked partial.
- **Get a plain explanation.** The optional Luna-low narrator explains what changed, what comes next, and what is stuck when worker activity changes.
- **Get one human answer.** Optional OpenClaw/Discord contact lets a fully blocked run ask its configured owner for help.
- **Check the workflow itself.** The optional alignment audit looks for conflicting instructions and rules that get in the agents' way.

## Install or update

Install the complete `de67` folder in your Codex skills directory. Keep its phase folders, scripts, references, assets, and integrations together. Start each phase yourself: `de67 1`, `de67 2`, then `de67 3`.

Requires Python 3.10+, the Codex CLI, and access to the configured Astra, Sol, Terra, and Luna models. Git is needed for repository work. The bundled detached service launcher targets macOS; the core Python workflow and optional dashboard are tested on Windows, Linux, and macOS.

Update the skill as a complete package. Existing project-local `.de67` guidance is a separate working copy: replacing the skill does not silently migrate an active campaign. Review local method changes at a normal handoff. Dashboard and narrator updates require restarting their own process to load the new source.

The dashboard, narrator, trajectory view, and OpenClaw contact remain optional. Core delivery does not need them. Live Discord delivery depends on your configured account and channel; release tests use isolated local fixtures.
