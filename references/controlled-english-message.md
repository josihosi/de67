# Controlled English for an owner message

Use this short profile for OpenClaw messages and owner questions.

- Ask for one decision or action.
- Name the blocked item.
- State the immediate reason and the smallest useful evidence.
- State what the owner must decide or do.
- Preserve technical identifiers exactly.
- Omit implementation history, internal jargon, and evidence that the owner does not need.
- Use `blocked` only when work cannot continue without external input. Use `waiting` for an
  expected event and `uncertain` when evidence is insufficient.

Technical precision overrides brevity. This profile is guidance, not a word-count gate.
