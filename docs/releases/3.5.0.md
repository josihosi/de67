# de67 3.5.0 — GPT-6.2 coordination and review

de67 now uses GPT-6.2 Sol at low effort for Phase 3 coordination and GPT-6.2 Astra at medium effort for mutation review. Phase 2 uses Astra 6.2 at high effort for specification review. GPT-6.1 Terra remains the preferred worker for clear, testable coding and for chaperoning direct Luna players. Use Sol for work with concrete ambiguity, substantial cross-system coupling, architectural decisions, or demonstrated difficulty. Choose thinking effort independently for each task.

Existing Sol and Astra bindings resolve to the current model IDs when a new turn launches. A resumed worker or mutator keeps its conversation and task ownership. Historical model IDs remain in probe records, review receipts, and usage attribution. Record freshly probed model and effort pairs in Phase 2. New rare Sol/ultra review snapshots require a successful Sol 6.2 ultra probe.

A worker can now change model or effort after returning a later, still-owned assignment when an earlier request remains ambiguous but can no longer act. Requests tied to the current assignment or an active worker server still block the handoff.

Upgrade the core and any installed add-ons together using matching archives and the published checksums. The dashboard, OpenClaw/Discord, Jev Telescope, and Jev Pit Crew remain separate and optional. The dashboard can display current and historical Astra sessions. Discord keeps direct owner input, blocked-only contact, and task-bound advisory consultation as distinct routes. The Jev add-ons remain experimental and disabled by default.

See the [installation and upgrade guide](https://github.com/josihosi/de67/blob/v3.5.0/docs/install.md), [dashboard setup](https://github.com/josihosi/de67/blob/v3.5.0/integrations/dashboard/README.md), and [OpenClaw/Discord setup](https://github.com/josihosi/de67/blob/v3.5.0/integrations/openclaw_discord/SETUP.md).
